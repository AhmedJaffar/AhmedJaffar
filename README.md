## Selected work

GitHub only lets me pin six repositories, so here is the fuller shelf.

### AI research & evaluation
- **[half-life-of-peace](https://github.com/AhmedJaffar/half-life-of-peace)** · Python — measuring public attention decay after ceasefires across 14 Wikipedia language editions (2015–2025).
- **[ai-prose-clock](https://github.com/AhmedJaffar/ai-prose-clock)** · Python — falsification-first audit of excess-vocabulary estimates of LLM-assisted writing; the clock ticks in biomedicine and fails in arXiv abstracts.
- **[OpenKeystroke](https://github.com/AhmedJaffar/OpenKeystroke)** · Python — open research platform for authorized acoustic keystroke side-channel experiments and privacy-defense evaluation.

### AI systems & products
- **[AI-Inference-Control-Plane](https://github.com/AhmedJaffar/AI-Inference-Control-Plane)** · JavaScript — measures AI inference cost and compares model configurations on the cost of accepted work.
- **[Inferix](https://github.com/AhmedJaffar/Inferix)** · Python — heterogeneous LLM inference system that routes requests across idle GPU workers behind an OpenAI-compatible API.
- **[sredcopilot](https://github.com/AhmedJaffar/sredcopilot)** ([live](https://sredcopilot.vercel.app)) · TypeScript — AI SR&ED claim copilot for Canadian companies.
- **[apexapply](https://github.com/AhmedJaffar/apexapply)** ([live](https://jobcopilot-ten.vercel.app)) · TypeScript — AI job application and interview copilot for high-income job seekers.
- **[BorderlessHire](https://github.com/AhmedJaffar/BorderlessHire)** ([live](https://borderlesshire.vercel.app)) · TypeScript — AI-native job platform for international students and global job seekers.

### Fintech, markets & DeFi
- **[Financial-Modeling-Toolkit](https://github.com/AhmedJaffar/Financial-Modeling-Toolkit)** · Python — forecasts, DCF valuation, portfolio construction and risk analysis.
- **[North-Terminal](https://github.com/AhmedJaffar/North-Terminal)** · Python — local crypto market-intelligence and paper-trading simulation platform (macOS app + Python server).
- **[rent-management-saas](https://github.com/AhmedJaffar/rent-management-saas)** · TypeScript — Canadian-first landlord rent management SaaS (Next.js, NestJS, Prisma, Stripe).
- **[CashinFruit](https://github.com/AhmedJaffar/CashinFruit)** · JavaScript — Hack Western 8 hackathon project.
- **Fibonacci DAO** — [white paper](https://github.com/AhmedJaffar/fibonaccidao), token and staking contracts ([FibDaoMint](https://github.com/AhmedJaffar/FibDaoMint), [FBDToken](https://github.com/AhmedJaffar/FBDToken), [ClaruswayStaking](https://github.com/AhmedJaffar/ClaruswayStaking), [SolidityContracts](https://github.com/AhmedJaffar/SolidityContracts)) and the [3D site](https://github.com/AhmedJaffar/3dfibdao).

### Everything else
- **[World-Bank-DataBase](https://github.com/AhmedJaffar/World-Bank-DataBase)** · Java — structured explorer over WHO data.
- **[TwitterSentiment](https://github.com/AhmedJaffar/TwitterSentiment)** · Python — LSTM study on whether Twitter sentiment tracks stock prices.
- **[SR-ED](https://github.com/AhmedJaffar/SR-ED)** — engineering-evidence workspace with an editable T661 technical narrative and GitHub ingestion.
- **[Beta_Avallon](https://github.com/AhmedJaffar/Beta_Avallon)** ([live](https://beta-avallon-frontend.vercel.app)) — AI-powered site generation and deployment platform.
- **[Monvoa](https://github.com/AhmedJaffar/Monvoa)** — AI product work in progress.
